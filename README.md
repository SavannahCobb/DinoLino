# DinoLino
An open source software for biological image analysis
©️CatfortSoftware 2018, 2026


Installation steps

This program is compatible with Windows. Download the zip file from the latest release "DinoLino.v3.0.0.zip" and extract all of it. Run setup.exe from the extracted folder to begin installation. Windows may warn that the publisher is unknown; choose "More info", then "Run anyway".

Updating

Check for updates by clicking "Check for Updates" in the Help menu. When an update is available, uninstall the current version (Windows Settings > Apps > Installed apps > DinoLino > Uninstall), then download the new zip file from the Releases page and install it as above. Uninstalling does not delete your saved projects.

Citing DinoLino

Please cite our upcoming article (Cobb et al, date TBD) in any publications that use DinoLino. More information will be posted on GitHub in future updates (and we have many updates and new features on the agenda), so please check for updates regularly in-app!
