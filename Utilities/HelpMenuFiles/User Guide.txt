USER GUIDE
------------------------------------------------------------------------------------------------
ABOUT DINOLINO:

DinoLino is a Windows program for 2D geometric morphometrics. It measures shape from photographs of specimens: curvature, angles, distances, and outlines.

Each image opened is treated as a specimen that keeps its own scale, alignment, picture corrections, and measurements. Operations are drawn in Curvature Mode, Triangle Mode, Draw Mode, or Outline Mode, and the operation history can be exported as an .xlsx workbook for statistical analysis.

The version number and list of contributors are in the About window of the Help menu.
------------------------------------------------------------------------------------------------
PROJECTS:

A project is a whole session in one file: every specimen with its picture, scale, alignment and picture corrections, every measurement together with the geometry behind it, the outlines kept as silhouettes, and the table state that goes with them. That last part covers the group columns, the formula columns, the variables chosen for the Custom table, the columns hidden from a table, and the tables staged for the workbook.

Save Project:
Writes the session to a project file. The first save asks where to put it, and later saves go back to the same file. Save Project As writes the session to another file and carries on in that one.

Open Project:
Replaces the session with the one in the file. Anything the current session holds that has not been saved is offered a save first.

New Project:
Empties the session and starts again, offering the same save first.

Autosave:
While a session holds anything a project file does not, DinoLino keeps a copy of it every few minutes, and again when the program closes. The copy is kept with the program's settings rather than beside the project, so a session that has never been saved is kept as well.

Closing the program asks nothing. If there was work outstanding, the next start offers it back, naming the project it belonged to and when it was kept. Saving the project, starting a new one and opening another all remove the kept copy, and so does turning the offer down.

Pictures:
A photograph is referenced by where it sits on disk rather than copied into the project, which keeps the project file small. The path is read relative to the project first, so a project and its photographs can be moved together as long as they keep the same arrangement. A picture that no file on disk reproduces is stored inside the project instead: a view captured from a 3D model, or an image rotated or flipped since it was opened.

A photograph that cannot be found when a project opens is named, and its specimen comes back with its measurements but no picture. Opening that image again brings the picture back.

The title bar shows which project the session belongs to, with a star beside the name while the session holds something the project file does not.

GLOBAL METHODS:

Undo:	
Undoes the last action performed by the user. This returns the metadata of the previous calculation and removes the last drawn operation.

Redo:	
Redoes the last action that was undone by the user. This returns the metadata of the next calculation and redraws the operation.

Clear:	
Clears all drawn operations and resets the metadata to its initial state for the current specimen. Also available as the Clear Specimen button.

Clear All:
Clears all specimens, measurements, and images from the session. A confirmation is shown first.

Zoom:
Use the scroll wheel to zoom in and out of the image at the location of the cursor.

Drag image:
Hold Ctrl and left click to drag and move the viewable window while zoomed in.

Move cursor:
Move the mouse, or hold Ctrl and press arrow keys to nudge the cursor one pixel at a time. Hold Shift and press arrow keys to move in larger steps.

Press the spacebar to left click at the cursor's position.

Averages:
The Avg column beside each output is the mean of that measurement across all operations of the same kind for the current specimen.

CURVATURE MODE: 

Geometric calculations to calculate curvature 

----- Circular Arc -----

Approximate a curve as the arc of a circle using three points. 
Click twice to draw a line from each end of the curve (your 'chord'), then click a third time in the midpoint of the curve to draw the chord bisector (your 'sagitta'). 
Click again after arc completion to begin another operation.

Central Angle: A measure of curvature. The angle, in degrees, subtended at the center of the circle passing through all three points.
Chord-Arc Ratio: A measure of curvature. The length of the first line drawn (chord) divided by arc length. Arc length = radius * central angle (in radians).
Rise-Span ratio: Length of the first line drawn (chord) divided by the length of its bisector (sagitta).
Radius: Radius of the circle passing through all three points.

----- Parabolic Arc -----

Approximate a curve as a parabola using three points.
Click twice to draw a line from each end of the curve (your 'chord'), then click a third time in the midpoint of the curve to draw the chord bisector (your 'sagitta'). 
Click again after arc completion to begin another operation.

The parabola y = ax^2 + bx + c is fitted through the three points with the chord scaled to unit length. Arc length is measured along 64 points sampled on the fitted parabola.

Chord-Arc Ratio: A measure of curvature. The length of the first line drawn (chord) divided by arc length.
Rise-Span Ratio: Length of the chord bisector (sagitta) divided by the length of the chord.
Vertex Curvature: Curvature at the vertex of the fitted parabola, equal to 2*a, taken as an absolute value. Dimensionless, because the chord is scaled to unit length.
Vertex Radius: Radius of curvature at the vertex, equal to chord length divided by vertex curvature.

----- n-Point Spline -----

Choose Catmull-Rom, Bezier, or Freehand, then draw along the curve. Beginning a new curve after one is finished starts another operation.

Catmull-Rom splines: The spline must pass through every point. This operation uses centripetal Catmull-Rom splines, which are well-suited for non-uniform biological shapes. Click any number of times along the curve, then press 'Enter' to finish.
Bezier splines: The spline is pulled towards the clicked points, but does not necessarily pass through them. This operation uses Schneider's Bezier fitting, with a tolerance of 2 pixels, to convert n points into one or more smooth cubic Bezier segments. Click any number of times along the curve, then press 'Enter' to finish.
Freehand: Click, hold the left mouse button, and drag along the curve. The spline is finished when the mouse button is released.

Splines are measured along 50 sampled points per segment.

Turn.Angles/Length: A measure of curvature. The sum of the turning angles (absolute change in angle of the tangent lines along the spline, in degrees) divided by the length of the spline. Approximates the average change in angle of the tangent lines along the spline.
Tortuosity: The length of the spline divided by the length of the straight line (chord) connecting its start and end points. Equal to 1 for a straight line.
Length: Length of the spline.

Freehand Smoothing:
Slider from 0 to 10, default 2. Filters hand tremor from the drawn stroke. Higher values give a smoother curve but pull it away from fine detail.
The stroke is resampled to points spaced 4 pixels apart, smoothed with a Gaussian filter of width 0.5 * Smoothing (in samples), and simplified with the Ramer-Douglas-Peucker algorithm at a tolerance of 2 + Smoothing pixels. A centripetal Catmull-Rom spline is fitted through the remaining points. At 0, no smoothing is applied.

----- Find Turning Angle / Length -----

Measures Turn.Angles/Length over a section of the most recently drawn spline instead of the whole curve. Move the cursor along the spline to choose the section. Section width sets the number of samples on each side of the cursor. Press Esc to exit.

TRIANGLE MODE:

Draws a triangle on the image and returns its three interior angles and proportions. 

Click three times anywhere on the image to create a triangle. Click again to begin drawing another triangle.

Angle A:		The angle at vertex A.
Angle B:		The angle at vertex B.
Angle C:		The angle at vertex C.
Aspect Ratio:	Length of the longest side of the triangle divided by its height.
Area:			Area of the triangle.
Relative Size:	Area of the current triangle divided by the area of the previous triangle.

Note: Triangle height is the perpendicular distance from its longest side to the opposite vertex.
------------------------------------------------------------------------------------------------
DRAW MODE:

Draw basic shapes and lines on the image and return their relative proportions.

----- Draw Shapes -----
Choose a rectangle, square, ellipse, or circle. Click once to begin drawing a geometric shape, drag to determine size and shape, and click a second time to finish.

Area: Area of the drawn shape.
Aspect Ratio: Width of the drawn shape divided by its height. Rectangles and ellipses only.
Relative Size: Area of the drawn shape divided by the area of the previous shape of the same kind.

----- Draw Lines -----
Click twice anywhere on the image to draw a straight line between two points.

Free: The line is unconstrained.
Parallel: The line is constrained parallel to the first constrained line drawn.
Perpendicular: The line is constrained perpendicular to the first constrained line drawn.
Angle: Type the desired angle in the text box. The line is constrained to that angle from the first constrained line drawn.

Length: Distance between the two points.
X Distance: Extent of the line along the specimen's X-axis (see Tools, Align Image). Uses the image's X-axis if no alignment is set.
Y Distance: Extent of the line along the specimen's Y-axis. X and Y Distance are always positive, and together with Length form a right triangle.
Line Ratio: Length of the drawn line divided by the length of the previous line.
Angle: Clockwise angle from the previous line to the drawn line, from 0 to 360 degrees. Constrained lines are measured from the first constrained line.

OUTLINE MODE:

Click objects to generate an enclosed outline around them.

----- Automated Outline -----
Click an object to outline it. Several segmentation methods are tried and the best-scoring outline that contains the clicked point is kept. If an AI segmentation model is installed, it is tried first. All processing is done on the local computer.

Fill Sensitivity:
For objects on a solid background, set fill sensitivity to the maximum value. 
Higher fill sensitivity values allows greater variation of colors and shades within the outlined object, but also increases chances of capturing background on non-uniform backgrounds.

Multi-Click:
Click multiple times to expand the outline. 
Click outside of the region bounded by a dashed line to expand the outline to include that region. 
Click inside the region bounded by a dashed line to finalize the outline.

Watershed:
Higher computational expense leads to slower execution, but it tends to yield a more accurate outline.
Better-suited for complex images (e.g., multi-toned objects, patterned objects, and/or objects on a non-uniform background).
Boundary Sensitivity sets the amount of blur applied before watershed: Off, Low, or High.

Tip: If the outline is not accurate, try adjusting the fill sensitivity, or switch between default and watershed methods.
Tip: To reduce computational expense and increase performance speed, try cropping or decimating the image.

----- Draw by Hand -----
Click, hold the left mouse button, and drag to draw an outline. The outline closes automatically when the stroke crosses itself.

----- Erase, Push and Local Smooth -----
Each of these reaches around the cursor rather than following it exactly, so the cursor carries a see-through yellow disc the size of the brush. It shows how much of the outline will be taken in before anything is touched, and it keeps that size as the image is zoomed.

----- Erase -----
Click, hold the left mouse button, and drag anywhere on the outline to erase that part. Set the eraser size using the slider.
Alternately, hold the 'Alt' button and drag the cursor to erase part of the outline. This may be more convenient when using a trackpad.

----- Push -----
Click, hold the left mouse button, and drag anywhere on the outline to push that part outward. Set the brush size using the slider.
Alternately, hold the 'Alt' button and drag the cursor to push part of the outline. This may be more convenient when using a trackpad.

----- Smooth -----
Smooth a noisy outline to the desired amount by adjusting the slider value. The higher the number of passes, the more smoothing will occur.
Global smooth smooths the entire outline, while local smooth smooths only the area around the cursor.
For local smooth, set the brush size using the slider and the desired strength. Click, hold the left mouse button, and drag anywhere on the outline to smooth that part. 
Alternately, hold the 'Alt' button and drag the cursor to smooth part of the outline. This may be more convenient when using a trackpad.

----- Generate Metadata -----
Before measuring, the outline is resampled to evenly spaced points. Without a scale, 512 points are used. With a scale, points are spaced by the Spacing value (default 0.05 units). The number of points is limited to between 64 and 4096.

Max Length: Maximum distance between any two points on the outline.
Max Width: Maximum extent of the outline perpendicular to Max Length.
Aspect Ratio (bbox): Width divided by height of the bounding box around the outline. The bounding box is aligned with the image edges.
Area: Area enclosed by the outline.
Perimeter: Length of the outline.
Circularity: 4π*Area / Perimeter^2
Solidity: Area of the outlined shape / Convex hull area
Convexity: Convex hull perimeter / Perimeter
Turn.Angles/Length: A measure of curvature. The sum of the turning angles (absolute change in angle of the tangent lines along the outline, in degrees) divided by the outline perimeter length. Approximates the average change in angle of the tangent lines along the outline.

Elliptic Fourier Analysis: Click to open a pop-up window to perform Elliptic Fourier Analysis (EFA) on the outline. The default number of harmonics is the smallest number that captures 99% of the cumulative harmonic power, and may be changed. Coefficients are normalized on the first harmonic. A warning is shown if the first harmonic is too small or too circular for a reliable normalization.

Commit Outline to History: Saves the outline and its metadata as an operation.

FILE:

----- Open Image ----- 
Resting on Open Image offers two kinds of file, 2D Image and 3D Model.

2D Image:
Open a 2D image file to analyze. Supported formats include .jpg, .png, .tif, and .bmp. 

3D Model:

Import a folder of images to analyze. Incompatible file types will be ignored.

Export the history of all operations performed. Undone or cleared operations will not be included. The exported file will be a workbook in .xlsx format, with each operation's history on a separate sheet.

Keep the current View menu settings for the next session.

----- Restore Default Settings -----
Return the View menu settings to their defaults.

EDIT:

----- Undo ----- 
Undoes the last operation performed. This removes the drawn elements and data associated with that operation. It will not be stored in the operation history.

----- Redo ----- 
Redoes the most recently undone operation. This reinstates the drawn elements and data associated with that operation.

TOOLS:

----- Set Scale -----
Click on two points in the image to draw a line. Enter the real-world length of the line in the input box and click "OK" to set the scale. 
This will allow the software to convert pixel measurements to real-world units. Available units are km, hm, dam, m, dm, cm, mm, micrometers, and nm.
Each specimen keeps its own scale. Measurements are shown as Unscaled until a scale is set.

----- Align Image -----
Set the specimen's X or Y axis by clicking two points on the image. The other axis is set perpendicular to it. Used for X Distance and Y Distance in Draw Mode.
Rotating or flipping the image removes the alignment.

----- Picture Corrections ----- 
Adjust brightness, contrast, or saturation of the uploaded image, from -100 to 100. Zero is the default value for all parameters. Each specimen keeps its own settings.

----- Decimate -----
Decimate the image by a specified factor to reduce its resolution and computational expense. This may be helpful for large images or when using the watershed method in outline mode. Enter a target pixel count or percentage.

----- Flip -----
Flip image horizontally or vertically to produce a mirror image.

----- Rotate -----
Rotate image by 90 degrees clockwise or counterclockwise.

----- Reposition 3D Object -----
Return to the 3D image viewer after capturing view of a 3D image to reposition the object. Click 'Capture View' when ready to save the new view as a 2D image, which the user can begin measuring.

----- Take Screenshot ----- 
Take a screenshot of the current software image screen. The screenshot may be saved as a .jpg, .png, or .tif file. The screenshot will include all drawn elements. 

----- Image Cache -----
Resting on Image Cache offers two choices, Clear and Edit. Neither removes any measurement.

Clear:
Remove all images from the cache without removing associated measurements.

Edit:
Review all cached images and remove them one at a time, without removing associated measurements.

----- See Batch Workshop -----
Edit and export data tables as CSV files for each mode. Toggle on or off to display on the right sidebar.

Formula Columns:
Click Edit beside Curvature Data, Angle Data, Shape Data, Outline Metadata or EFA Data, then Add column, to make a new variable calculated from that table's columns. Enter a name of up to 14 characters and a formula, such as = outline_area / outline_perim^2. Column names may be typed straight into the formula, or found in the list beside it and inserted.
Each tab of the History window carries the same button. A column added from a tab belongs to the table that tab is part of, and is edited or deleted from that table's Edit window.
A column name in a formula stands for that column's value on the same row. Formulas use addition, subtraction, multiplication, division and powers, with brackets to group them. Comparisons are written = <> < <= > >= and give 1 or 0, as in IF(outline_area > 100, 1, 0).
Row functions: SUM, PRODUCT, AVERAGE, MIN, MAX, COUNT, MEDIAN, ABS, SQRT, LN, LOG, LOG10, EXP, POWER, MOD, ROUND, INT, SIGN, PI, SIN, COS, TAN, ASIN, ACOS, ATAN, ATAN2, DEGREES, RADIANS, IF, IFBLANK, ISBLANK.
Whole-column functions, taken over every specimen: COLSUM, COLMEAN, COLMIN, COLMAX, COLCOUNT, COLMEDIAN, COLSD.
Specimen functions, taken over the row's own specimen: SPECSUM, SPECMEAN, SPECMIN, SPECMAX, SPECCOUNT, SPECMEDIAN, SPECSD.
Each of these takes one column name, as in SPECMEAN(outline_area). COLSD and SPECSD are sample standard deviations, which need at least two values.
A blank cell is not zero. Any arithmetic using a blank cell gives a blank result, so a row without that measurement is left empty rather than counted as zero. SUM, PRODUCT, AVERAGE, MIN, MAX, COUNT and MEDIAN skip blank arguments, and IFBLANK(value, 0) puts a number in their place. A calculation with no numerical answer, such as division by zero, shows #ERR.
Cells carry their units, such as 4.56 cm, and a formula reads the number in front of the unit. Results are plain numbers rounded to 4 decimal places, so a formula that mixes scaled and unscaled specimens mixes their units as well.
A row holds attempt n of every operation kind in its table, so a formula combining two kinds combines their nth attempts.
Formula columns are recalculated whenever a table is built, and appear in the table, in its CSV and workbook exports, in the History window, and among the variables offered in the Plot tab and Principal Component Analysis. A formula may use any formula column made before it. The pencil button on a column header edits or deletes the column, and the X button hides it as for any other column.
Formula columns last for the session and are removed by Clear All.

Custom Table:
The History window has a Custom tab that builds one table from variables of any mode. Tick the variables on the left; each one is added as a column in the order it is ticked, and Clear all empties the choice.
Rows follow the same rule as a single mode's table: attempt 1 of every kind shares a row, attempt 2 the next, and a kind with fewer attempts leaves blank cells. Specimen and group columns are included as in every other table.
Add column writes a formula column for this table, so measurements of different modes can be combined, for example = outline_area / tri_area. These columns are edited from the Formula columns list on the left.
Export to CSV writes the table as custom_data.csv, and Add to workbook includes it in the exported workbook as a sheet named Custom. The choice of variables lasts for the session and is removed by Clear All.

EFA Data:
The coefficients table may be exported in wide format in Batch Workshop, or it may be exported in the Elliptic Fourier Analysis window.

2D Outlines:
All outlines created in a session may be exported as black silhouettes on a white background. Outlines are automatically filled prior to export.
All generated outlines will be exported unless they are manually removed in the Edit window.
Select a destination folder for export, a file type (.png, .tif, .bmp, .jpg, or .svg), and desired canvas size.
Scale: Outline area will be resized such that the filled shape covers 25% of the canvas. 
	   Some elongated shapes are exceptions to this. If an elongated shape at target area reaches past the margins, it is shrunk until it fits within the canvas.
Align: Outlines may be rotated onto the long axis to align orientations, or exported in original orientation.

----- See Directory -----
Navigate file paths, view, and edit the specimens uploaded for a given a session.

Files:
Browse folders and open images or 3D models.
The working directory can be set three ways: right-click a folder and choose Set Working Directory, click a folder and then click Set, or type or paste a path into the box and click Set or press Enter. Clicking a folder puts its path in the box, so what Set is about to apply is always the path on screen.

Sample:
View, rename, load, duplicate, or delete specimens in the session.

Plot:
Plot recorded measurements as a scatter plot, boxplot, dot plot, histogram, or QQ plot, and export the plot as an image.
Principal Component Analysis (PCA): Add two or more variables, then run the analysis. Variables are centered on their means. If standardization is selected, each variable is also divided by its standard deviation (correlation-matrix PCA).

A friend to help you work.

----- See History ----- 
View and export CSV tables of all operations performed.

----- Line Options ----- 
Opens a window holding the color and the thickness every mode draws at. Both take effect as they are chosen, so the window can be left open while the change is judged against the image underneath.

Color: Adjust color of drawn elements. Multiple options are available to accommodate colorblindness and ensure operation visibility on any image.

Thickness: Adjust the width of drawn elements, from 0.5 to 10. A thin line sits closer to a feature's edge on a large photograph; a thick one stays visible on a small or busy one.

With See Previous Operations switched on, the measurements already on screen are drawn again in the new style. The guide marks a tool shows while a measurement is being made keep their own weight, since they say where a measurement will go rather than being part of one.

----- Font ----- 
Adjust font size or font family. Dyslexia-friendly fonts are available. 
If needed, you may accommodate very large font sizes by resizing the sidebar or program window with clicking and dragging.

----- Column names and abbreviations -----

Column names in data tables correspond to the following: 

"Specimen" = Specimen Name
"Attempt" = Operation Count

In Curvature Mode:
"circ_centangle" = Central Angle of Circular Arc
"circ_chordarc" = Chord-Arc Ratio of Circular Arc
"circ_risespan" = Rise-Span Ratio of Circular Arc

"tri_anglea" = Angle A of Triangle
"tri_angleb" = Angle B of Triangle

"tri_aspect" = Aspect Ratio of Triangle

In Draw Mode:
"rect_aspect" = Aspect Ratio of Rectangle
"rect_area" = Area of Rectangle

"ellipse_aspect" = Aspect Ratio of Ellipse
